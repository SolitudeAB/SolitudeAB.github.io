引言

图像滤镜功能可让您对照片应用各种特效。此处描述的图像滤镜类型采用二维滤镜，类似于 Paint Shop Pro 中的”用户自定义滤镜”和 Photoshop 中的”自定义滤镜”功能。

卷积运算

图像滤镜的核心原理在于：您拥有一个二维滤镜矩阵和一张二维图像。随后，针对图像的每个像素，计算乘积之和。每个乘积由当前像素或其邻近像素的颜色值与滤镜矩阵对应位置的值相乘得出。滤镜矩阵中心值需与当前像素相乘，而矩阵其余元素则与对应的邻近像素相乘。

这种对两个二维函数的元素进行乘积求和，并让其中一个函数遍历另一个函数每个元素的操作，被称为卷积或相关运算。卷积与相关的区别在于：卷积运算需要翻转滤镜矩阵，但通常矩阵本身具有对称性，因此两者并无实际差异。

使用卷积的滤波器相对简单。当然也存在更复杂的滤波器，它们能够运用更花哨的函数，实现更为复杂的效果（例如 Photoshop 中的彩色铅笔滤镜），但此类滤波器不在本文讨论范围内。

二维卷积运算需要四重循环，因此除非使用小型滤波器，否则速度并不算特别快。我们通常使用 3x3 或 5x5 的滤波器。

关于滤波器有几条规则：

  • 其尺寸必须为奇数，这样才能具有中心点，例如 3x3、5x5 和 7x7 都是可行的。
  • 虽然并非强制要求，但若希望处理后图像的亮度与原始图像保持一致，滤波器所有元素之和应为1。
  • 如果元素之和大于1，结果将得到更亮的图像；如果小于1，则图像会变暗。若总和为0，生成的图像不一定是全黑，但会非常暗淡。

图像具有有限尺寸，例如在计算左侧像素时，其左侧已无更多像素可供卷积运算使用。此处可采用0值填充，或采用图像对侧回绕的方式。本教程选择回绕方式，因为通过模除运算即可轻松实现。

应用滤波器后生成的像素值可能为负数或超过255，若出现这种情况，可采用截断处理：将小于0的值设为0，大于255的值设为255。对于负数值，亦可采用取绝对值的方式处理。

在傅里叶域或频域中，卷积运算会转变为乘法运算，速度更快。在傅里叶域中，可以更快速地应用更强大、更大型的滤波器，尤其是在使用快速傅里叶变换时。更多相关内容请参阅傅里叶变换专题文章。本文将重点介绍几种典型的小型滤波器，例如模糊、边缘检测和浮雕效果。

图像滤波器目前尚未能实时应用于游戏场景，但在图像处理领域极具实用价值。

数字音频和电子滤波器同样采用卷积原理运作，不过是在一维空间中实现。

如果您的卷积核是一个全部填充相同值的方框（通过适当的缩放因子使所有元素之和为 1.0），那么这种模糊效果被称为方框模糊。若需要实现大尺寸的方框模糊，本教程中的基础卷积代码会运行过慢。但您可以通过更高效的算法轻松实现：由于每个像素值的权重相同，您可以逐行遍历图像像素，累加 N 个像素值（N 为方框宽度）后除以相应缩放因子。随后每移动一个像素，只需加上新进入方框的像素值，并减去离开方框的最左侧像素值。完成水平方向的逐行处理后，以相同方式垂直处理（为优化 CPU 缓存使用，垂直处理时需确保仍按扫描线顺序操作而非按列操作，因此需要为每列存储累加值）。整个过程需特别注意边界处理（当方框部分越界时）以及图像尺寸小于方框的情况。此处不提供具体代码实现，因为这略微超出了本教程的范围。

高斯模糊

在上述模糊处理中，我们使用的卷积核效果较为生硬。而高斯核能实现更平滑的模糊效果——其数值随着与中心点距离的增加呈指数级衰减。计算公式为：G(x) = exp(-x x / 2 sigma sigma) / sqrt(2 pi sigma sigma)

对于二维情况，您可以在 X 方向应用此公式，然后在 Y 方向应用（它是可分离的），或者合并后得到：G(x, y) = exp(-(x x + y y) / (2 sigma sigma)) / (2 pi sigma * sigma)

在公式中：
) sigma 决定半径（理论上半径是无限的，但在实践中由于指数衰减，存在一个小到看不见的临界点，sigma 越大这个临界点越远） ) x 和 y 必须是坐标值，且 0 位于卷积核中心

上述公式说明了如何生成任意大小的卷积核。不过这里提供可直接使用的简单示例：

3x3 卷积核的近似值：

#define filterWidth 3 #define filterHeight 3 double filter[filterHeight][filterWidth] = { 1, 2, 1, 2, 4, 2, 1, 2, 1, }; double factor = 1.0 / 16.0; double bias = 0.0;

近似于 5x5 核：

#define filterWidth 5 #define filterHeight 5 double filter[filterHeight][filterWidth] = { 1, 4, 6, 4, 1, 4, 16, 24, 16, 4, 6, 24, 36, 24, 6, 4, 16, 24, 16, 4, 1, 4, 6, 4, 1, }; double factor = 1.0 / 256.0; double bias = 0.0;

一个精确而非近似的例子：

#define filterWidth 3 #define filterHeight 3 double filter[filterHeight][filterWidth] = { 0.077847, 0.123317, 0.077847, 0.123317, 0.195346, 0.123317, 0.077847, 0.123317, 0.077847, }; double factor = 1.0; double bias = 0.0;

对于较大半径（例如您可以在具有高斯模糊功能的绘图程序中尝试），需要更大的卷积核。本教程中使用的简单卷积实现在处理大半径高斯模糊时实际应用会变得过于缓慢。但对此有解决方案：使用本系列傅里叶变换教程中描述的傅里叶变换方法，或者采用更快速的近似算法——通过连续执行多次方框模糊（连续三次即可实现相当精确的近似）。快速方框模糊的实现方法已在上一章节中说明。这种方法的数学原理在于：高斯分布本身就是多个独立过程叠加的自然产物。

浮雕

浮雕滤镜能为图像赋予三维阴影效果，这种效果非常适合用作图像的凹凸贴图。其实现原理是：取中心点一侧的像素值，减去另一侧的像素值。像素运算结果可能为正数或负数。若要将负值像素作为阴影、正值像素作为高光来生成凹凸贴图，需为图像添加128的偏移量。此时图像大部分区域将呈现灰色，边缘区域则会显示深灰/黑色或亮灰/白色。

中值滤波器的原理类似，但并非取平均值，而是取中位数。中位数的获取方式是将所有数值从低到高排序后取中心值。若中心存在两个数值，则取这两个数值的平均值。中值滤波器在去除椒盐噪声方面效果更佳，因为它能完全消除噪声。使用均值滤波器时，噪声点的色值仍会被纳入平均计算，而采用中值滤波时仅保留一个或两个正常像素的色值。不过中值滤波器同样会降低图像质量。

这种中值滤波器无法通过卷积实现，需要采用排序算法，本例选用的是梳排序算法——一种相对高效的排序方式。

要获取当前像素及其八个相邻像素的中值，需将滤波器宽度和高度设置为3，但也可增大该值以消除更大的噪点颗粒。

旁注：上述中值算法实现非常缓慢。无论是使用 C++的 nth_element 函数还是这里的玩具版”selectKth”实现，对于 9 个或 25 个数值的中值计算都收效甚微。无论算法在大规模 N 值下的理论复杂度如何，当仅处理特定有限规模的小型输入时，必须采用最适合该输入尺寸的方案。

若需实现 3x3 中值滤波，最快捷的方式是采用硬编码的九元素排序网络，直接取其中间输出值作为中位数。随后对每个输出像素对应的九个输入像素逐一应用此操作，且需在每个颜色通道上独立执行。硬编码的优势在于算法无需包含与输入尺寸相关的条件判断（如 if 语句和循环条件，这类条件会中断 CPU 流水线，显著降低运行效率）。本文不提供具体代码，因为高效的实际实现已超出本教程范畴。如有兴趣，可查阅排序网络相关资料——这是一种通过硬编码的二元数值交换序列（根据最大值判定进行交换），需选用已被证明在目标输入规模下最优的方案。由于我们不需要完整排序而仅需获取中位数元素，可省略所有不影响中间元素输出的交换操作，并将仅单侧输出影响中间元素的交换替换为取最小值或最大值操作。 这将提供理论上最快的实现方式，在此基础上进一步的加速只能通过利用并行性和/或更优的 CPU 指令来实现。
