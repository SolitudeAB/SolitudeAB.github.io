您可以按照以下步骤解决这个问题：

第一步：手动安装 PyTorch 和 Torchvision

我们需要告诉 pip 去 PyTorch 的专用仓库寻找这些特定版本。

请直接在终端运行以下命令（假设您使用的是 Python 3.8，且对应 PyTorch 1.8.1/Torchvision 0.9.1）：

Bash

命令解释：

  • -f https://download.pytorch.org/whl/torch_stable.html：这告诉 pip 去 PyTorch 的官方 wheel 列表中查找，而不是只在 PyPI 里找。
  • 我们显式指定了 torch==1.8.1+cu102，因为 torchvision 0.9.1 必须配合 torch 1.8.1 使用。

第二步：修改 requirements.txt (可选但推荐)

为了防止再次报错，建议您打开项目中的 requirements.txt 文件：

  1. 找到 torch==... 和 torchvision==... 这两行。
  2. 在它们前面加上 # 号注释掉，或者直接删除它们（因为我们在第一步已经手动安装好了）。

第三步：安装剩余依赖
