命令 python train.py —dataroot ./datasets/fundus —name fundus_cyclegan —model cycle_gan
./datasets/fundus —gpu 0 这个表示数据存放路径

测试命令：
python test.py \
—dataroot ./datasets/fundus/testA \
—name fundus_cyclegan \
—model test \
—no_dropout \
—model_suffix _A

python test.py \
--dataroot ./datasets/fundus/testA \
--name fundus_cyclegan \
--model test \
--no_dropout \
--model_suffix _A \
--preprocess none  # <--- 关键修改：不做缩放和裁剪

进服务器后

  1. tmux new -s exp_session # exp_session 是会话名称，可自定义
    2.如果没有直接进这个会话，用tmux ls 看到自己刚刚创建的
    3.tmux attach -t exp_session 进去
    4.开始训练
    5.按ctrl+b后触发快捷键模式，这一步不会有提示，然后松手，按d

1. 基础命令

Bash

2. 参数解释

  • --continue_train：
    • 这个开关告诉程序：“不要随机初始化，去 checkpoints 文件夹里找最新的权重文件（通常是 latest_net_G.pth）加载进来”。
  • --epoch_count N：
    • N = 你想从第几轮开始计数。
    • 比如你上次跑完了 Epoch 20，这次你想让日志显示为 Epoch 21，你就设 --epoch_count 21。
    • 注意：这个参数主要影响日志打印和学习率衰减的计算，不会影响权重加载（权重是按 latest 自动加载的）。

3. 进阶技巧（加载特定版本）

如果你觉得第 50 轮的效果比第 60 轮好，想“回滚”到第 50 轮继续练：

  • 加入参数 --epoch 50。
  • 程序就会去加载 50_net_G.pth 而不是 latest_net_G.pth。
  • 同时记得把 --epoch_count 设为 51。
