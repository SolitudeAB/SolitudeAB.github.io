手搓GPT计划

发表于2026-01-05|更新于2026-07-04|笔记
|总字数:1.1k|阅读时长:3分钟

这完全合理。你描述的正是目前主流大语言模型（如 ChatGPT, Llama）的标准训练流水线： 自回归 $\rightarrow$ Pretrain $\rightarrow$ SFT $\rightarrow$ RLHF。

虽然《Attention Is All You Need》这篇论文主要讨论的是用于翻译的 Encoder-Decoder 架构 ，但要实现你的目标（手搓 GPT），你需要剥离出论文中的 Decoder 部分，并按照以下四个阶段执行。

鉴于你的 PyTorch 和 CycleGAN 经验，这不仅仅是“可行”，而且是一个极佳的进阶项目。以下是基于这一路径的具体实战计划：

第一阶段：搭建骨架（Model Architecture）

目标：用 PyTorch 写出一个“未经训练的 GPT”。

这一步是复现论文中的 Decoder 结构，但要去掉处理 Encoder 输入的 Cross-Attention 层。

  1. Decoder-Only 架构：
    • 你需要实现 $N$ 个堆叠的层（Stack of $N=6$ identical layers）3。
    • 每一层保留两个子层：Masked Multi-Head Attention 和 Position-wise Feed-Forward Networks 4。
  2. 核心难点（Masking）：
    • 论文中强调，Decoder 中的自注意力机制必须被修改（Masked），以防止位置 $i$ 关注到 $i$ 之后的位置 。
    • 你需要在 Softmax 之前，给 Attention Score 的右上三角部分加上负无穷大（$-\infty$），确保预测当前词时看不到未来的词。
  3. 输入与输出：
    • 实现 Input Embedding + Positional Encoding。
    • 输出层是一个线性层 + Softmax，映射回词表大小。

第二阶段：预训练（Pretraining）

目标：让模型学会“说人话”（掌握语法、知识）。

状态：此时模型是“接龙高手”，你给它“今天天”，它接“气不错”。

  1. 数据准备：
    • 入门级：用 TinyShakespeare（莎士比亚文集），几 MB 大小，几分钟就能跑完，适合调试代码跑通流程。
    • 进阶级：TinyStories 或 OpenWebText 的切片。
  2. 训练任务：
    • 自回归（Auto-regressive）：输入是 $x_t$，目标是 $x_{t+1}$ 9。
    • Loss：标准的 CrossEntropyLoss。
    • Optimizer：论文推荐 Adam ($\beta_1=0.9, \beta_2=0.98$) 并配合学习率预热（Warmup）
  3. 产出：Base Model（基座模型）。

第三阶段：指令微调（SFT - Supervised Fine-Tuning）

目标：让模型学会“听指令”（不仅是续写，而是回答问题）。

状态：此时模型变成了“对话助手”。

  1. 数据格式变化：

    • Pretrain 的数据是纯文本。

    • SFT 的数据是 (Instruction, Input, Output) 对。

    • 你需要构建特殊的 Prompt 模板，例如：

      Plaintext

  2. 训练过程：

    • 加载第二阶段训练好的 Base Model 权重。
    • 使用高质量的指令数据集（如开源的 Alpaca 或 Dolly 数据集）。
    • 训练原理和 Pretrain 一样（还是预测下一个 token），但只计算 <|assistant|> 回答部分的 Loss，忽略用户提问部分的 Loss（这叫 Data Masking）。

第四阶段：人类反馈强化学习（RLHF / DPO）

目标：让模型符合人类偏好（更有帮助、更安全、不仅是正确）。

状态：这是目前大模型的“完成体”。

警告：这也是最难、最不稳定的一步。如果你是个人开发，我强烈建议先用 DPO (Direct Preference Optimization) 替代传统的 PPO-RLHF，效果类似但更简单。

如果要走标准的 RLHF (Reinforcement Learning from Human Feedback) 流程：

  1. 训练奖励模型 (Reward Model, RM)：
    • 你需要这种数据：(Prompt, Good_Answer, Bad_Answer)。
    • 训练一个 BERT 或小 GPT，让它给 Good 打高分，Bad 打低分。
  2. PPO 强化学习：
    • 冻结你的 SFT 模型，复制一份作为 Actor。
    • 让 Actor 生成回答，RM 给分。
    • 用 PPO 算法更新 Actor 的参数，让它生成的回答得分更高，同时不要偏离原模型太远（KL Divergence 惩罚）。

总结与行动建议

对于“手搓”而言，Phase 1 (架构) + Phase 2 (Pretrain) 是最核心的，也是最能学到东西的。Phase 3 和 4 更多是数据工程和微调技巧。

我的建议步骤：

  1. Hello World：先基于《Attention Is All You Need》复现一个 Mini-GPT。
    • 配置：$d_{model}=64, N=4, Heads=4$。
    • 数据：莎士比亚数据集。
    • 目标：Loss 能下降，生成的文本看起来像古英语。
  2. Scale Up：
    • 增加层数到 $N=12$ 11，维度 $d_{model}=768$。
    • 引入 BPE (Byte-Pair Encoding) 分词器 12。
  3. Chatbot：
    • 找一份开源的 SFT 数据集（json格式），微调你的模型，看它能不能回答简单问题。

你可以从现在就开始。你想让我帮你先梳理 Phase 1 的核心代码结构（Masked Attention 的 PyTorch 实现），还是想了解一下需要准备什么规模的数据？
