第一步：理解“搬家”规则

我们需要把你现有的文件夹映射到 I-SECRET 要求的结构中去：

  1. normlight_image (正常光/高质量) $\rightarrow$ 对应 crop_good
    • 这是你的“标准答案”（Ground Truth）。
  2. lowlight_image (低光/低质量) $\rightarrow$ 对应 crop_usable
    • 在论文里，usable 指的是真实的低质量图片，用于无监督学习（让模型看各种真实的烂图，学习怎么适应）。
  3. degrade_good (人工降质图) $\rightarrow$ 暂时留空
    • 这个文件夹现在不需要你放图片。等你分好类之后，运行作者的 degrade_eyeq.py，它会自动读取你的 crop_good，生成对应的模糊图填进去。

这是一个非常经典的 Linux 环境库版本冲突问题，在深度学习服务器上特别常见。

🔴 问题原因

简单来说：

  1. 你安装的 SimpleITK 依赖一个叫 libtbb 的库。
  2. 这个 libtbb 需要比较新的 C++ 标准库支持（具体是需要 CXXABI_1.3.15 版本）。
  3. 但是，你的 Linux 系统默认去找了系统自带的老版本 C++ 库（位于 /lib/x86_64-linux-gnu/libstdc++.so.6），那里没有这个新版本。
  4. 其实，你的 Conda 环境里已经有这个新版本的库了，只是系统“近视眼”没看见。

✅ 解决方法

我们只需要“强制”告诉系统：先去 Conda 环境里找库，别去系统默认的地方找。
