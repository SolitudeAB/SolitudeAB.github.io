第一部分：你的网络 (SCR-IG) 损失函数体系

你的网络采用的是“多损失联合优化”策略，总损失由监督分支、无监督分支以及语义对比约束三部分组成：

$\mathcal{L}_{Total} = \alpha \mathcal{L}_{Sup} + \beta \mathcal{L}_{Unsup} + 0.01 \mathcal{L}_{ICC\_Ours}$

(注：在你的 train.py 中，对比损失的权重被缩小为 0.01 以防止走火入魔)

1. 监督分支：正向重要性加权的修正 IS-Loss ($\mathcal{L}_{Sup}$)

你放弃了 I-SECRET 的“倒数规避”逻辑，转而使用正向的指数放大机制（$\exp$），强制网络将注意力集中在病灶和毛细血管（$\overline{\alpha}_i$ 趋近于 1）的区域：

$\mathcal{L}_{Sup} = \mathcal{L}_{IS\_Retinex} = \frac{1}{N} \sum_{i=1}^{N} \exp(\lambda \cdot \overline{\alpha}_{i}) \left\| z_{pred}^{(i)} - z_{GT}^{(i)} \right\|_2^2$

  • $z_{pred}$ 是网络基于 Retinex 还原的反射图（增强图）。
  • $\overline{\alpha}_{i} = \max(\alpha_{lesion}^{(i)}, \alpha_{vessel}^{(i)})$ 是该像素的绝对重要性先验。
  • $\lambda$ 是控制注意力强度的超参数（在代码中 lambda_val = 2.0）。

2. 无监督分支：带约束的物理校准损失 ($\mathcal{L}_{Unsup}$)

这一部分完全脱离了 I-SECRET，是你结合 SCI 物理架构做出的独创性改良，它由三项组成：

$\mathcal{L}_{Unsup} = 1.5 \mathcal{L}_{Fid} + 1.0 \mathcal{L}_{IMS} + 0.5 \mathcal{L}_{Color}$

  • 全局保真度损失 (Fidelity Loss)：驱动图像提亮的核心引擎，强制光照图 $x$ 贴近输入暗图 $y$。

    $\mathcal{L}_{Fid} = \frac{1}{N} \sum_{i=1}^{N} \left\| x_{pred}^{(i)} - y^{(i)} \right\|_2^2$

  • 重要性调制的空间平滑损失 (Importance-Modulated Smoothness, IMS)：利用 24 方向梯度 $W_{i,j}$ 平滑背景去噪，但通过 $(1 - \gamma \overline{\alpha}_{i})$ 强行豁免/保护毛细血管区。

    $\mathcal{L}_{IMS} = \sum_{i=1}^{N} \sum_{j \in \mathcal{N}(i)} W_{i,j} (1 - \gamma \overline{\alpha}_{i}) \left\| x_{pred}^{(i)} - x_{pred}^{(j)} \right\|_1$

  • 色彩一致性约束 (Color Constancy Loss)：消除光照估计引发的黄绿/红蓝色偏。

    $\mathcal{L}_{Color} = \frac{1}{N} \sum_{i=1}^{N} \left[ (x_R - x_G)^2 + (x_R - x_B)^2 + (x_G - x_B)^2 \right]$

3. 语义感知对比约束 ($\mathcal{L}_{ICC\_Ours}$)

计算 Patch 级别的特征（$v_l$ 为低质特征，$v_l^+$ 为同一位置的增强正样本，$v_l^-$ 为负样本），并将重要性图下采样后直接作为 InfoNCE 损失的正向乘法权重：

$\mathcal{L}_{ICC\_Ours} = - \sum_{l} \overline{\alpha}_{l} \log \left( \frac{\exp(v_l \cdot v_l^+ / \tau)}{\exp(v_l \cdot v_l^+ / \tau) + \sum \exp(v_l \cdot v_l^- / \tau)} \right)$

第二部分：I-SECRET 论文原版损失函数体系

I-SECRET 的总损失是一个庞大的组合，包含了监督、对抗、对比等多个维度：

$L = \lambda_{IS} L_{IS} + \lambda_{ADV} L_{ADV} + \lambda_{ICC} L_{ICC} + \lambda_{IDT} L_{IDT}$

(注：原文中作者将这些权重 $\lambda$ 均简化设置为了 1)

1. 监督分支：基于不确定性的 IS-Loss

这就是采用“同方差不确定性”（通过降低困难区域梯度来防止损失爆炸）的经典公式：

$\mathcal{L}_{IS}(\theta_{\mathcal{G}}) = \frac{1}{N}\sum_{i=1}^{N} \frac{1}{\exp(\alpha_{i})} \mathcal{L}_{MSE} + \frac{1}{N}\sum_{i=1}^{N}\alpha_{i}$

(在原文中，$\alpha_i$ 不是提取的固定先验，而是网络预测出的不确定性/重要性权重)

2. 无监督对比约束：ICC-Loss

它在标准的 InfoNCE 损失前面，同样乘上了重要性图的指数倒数 $\frac{1}{\exp(\alpha_{l}^+)}$：

$L_{ICC} = -\sum_{l\in L}\frac{1}{\exp(\alpha_{l}^+)} \log\left[ \frac{\exp(v_{l}\cdot v_{l}^+/\tau)}{\exp(v_{l}\cdot v_{l}^+/\tau) + \sum \exp(v_{l}\cdot v_{l}^-/\tau)} \right]$

3. 生成对抗损失：Adversarial Loss (LS-GAN)

为了让增强出来的图片更具真实感（骗过判别器 D），I-SECRET 使用了最小二乘 GAN 损失：

$L_{ADV}(\theta_{\mathcal{G}}) = \min_{\mathcal{G}} \frac{1}{2} \mathbb{E}_{x\sim X} \left[ D(G(x)) - 1 \right]^2$

4. 身份一致性损失：Identity Loss

为了防止对抗网络“过度发挥”改变原始图像内容，I-SECRET 引入了防过度增强的身份对比损失（即输入高清图 y，得到的特征应当自我一致）：

$L_{IDT} = -\sum_{l\in L} \log\left[ \frac{\exp(v_{l}^*\cdot v_{l}^{*+}/\tau)}{\exp(v_{l}^*\cdot v_{l}^{*+}/\tau) + \sum \exp(v_{l}^*\cdot v_{l}^{*-}/\tau)} \right]$

最后总结一句你可以在论文里强调的话：

在损失函数的工程设计上，I-SECRET 主要是“躲避困难”（即用 $1/\exp(\alpha)$ 降低对困难的微血管区域的惩罚要求）；而你的 SCR-IG 则是“迎难而上”（用 $\exp(\alpha)$ 对微血管区开出天价惩罚，强制要求其完美重建）。这在数学逻辑上构成了你对比 Baseline 的底层优势。
