随笔2026.3.8

发表于2026-03-08|更新于2026-07-04|论文实验
|总字数:1.3k|阅读时长:4分钟

随着论文阅读量的增加和我所谓理想架构的搭建，我算是对深度学习有了一知半解。

要探讨一个网络模型的合理性，我觉得应该从以下几个方面考量

  1. 网络的创新点

    • 当然要和最新的网络模型相比较：比方说sota指标（PSNR、SSIM），还有运行效率，成本，应对极端情况的表现型（也就是说模型的泛化能力，这应该就不得不提到无监督训练的重要性了）

    我最近看到的是半监督模型的优势，我觉得说的很有道理啊，单纯的无监督虽然泛化能力强，但它对于细节的保真效果就相对更弱啊；而单纯的有监督，虽然对于细节的描绘很有优势，但是它对于没见过的场景，就很吃瘪了，所以引出了半监督——我都有，两个各有优劣，我干嘛只要选择一种，不能兼顾吗，尽管会损失一部分精度。

    但是，怎么把这两个部分训练得到的权重结合起来，这倒是个值得考虑的问题

  2. 模型的目的意义

    • 比如医学模型，你要在医学上解决什么问题？像下游任务，就是解决医学图像的增强问题，方便医生诊断疾病（这里的医生是广义的，也可以是智能体医生——当然这也是目前顶刊顶会人才的发展方向，我觉得可以走，但是太容易想到了，也有可能你刚做出来，别人已经把文章发出来了）

    像下边的，就算詹博给我发的目前Agentic AI 的发展方向1. 数字病理（WSI）的“导航与证据链”构建

    由于数字病理图像（WSI）分辨率极高，Agent 的核心任务是解决“从海量像素中高效定位并提取关键诊断信息”的问题 。

    • 模拟诊断逻辑：模仿病理学家“先粗后细、边看边记、最后总结”的流程 。
    • 多智能体分工：
      • 分诊/导航 Agent：负责在全片中寻找可疑区域（ROI） 。
      • 描述 Agent：对发现的区域生成自然语言证据描述 。
      • 诊断整合 Agent：汇总所有局部证据，给出最终结论 。
    • 代表工作：PathFinder 和 WSI-Agents 。

    2. 放射学报告的“知识注入与事实核对”

    为了解决大模型（LLM）在生成报告时的“幻觉”问题，Agent 的任务是将外部权威知识与视觉特征深度对齐 。

    • 层级决策：决定每一句报告是应该调用既有的“模板库”，还是需要动态生成 。
    • 工具化增强：将疾病知识图谱、视觉编码器作为“外部工具”调用，把视觉特征转换为结构化的异常图 。
    • 减少幻觉：通过“检索-生成”混合决策，确保临床术语的专业性和准确性 。

    3. 手术室（OR）工作流的“查询分解与推理”

    在复杂的手术室环境中，Agent 的任务是将模糊的临床提问转化为可执行的视觉分析任务。

    • 任务拆解（Planner）：将类似“手术效率为何低下”的问题拆解为多个子查询（如：器械使用频率、人员流线分析） 。
    • 数字孪生推理：在数字孪生表征上进行推理分割（Reasoning Segmentation），并合成多模态证据 。
    • 提供视觉证据：输出结果时附带 RS Mask（推理分割掩膜），让诊断过程对医生透明、可回溯 。

    4. 成像链路中的“自适应主动采样”

    这是一种处于成像最前端的任务，Agent 负责在扫描过程中实时优化策略 。

    • 规划-执行-反馈闭环：每完成一步采样，Agent 都会根据当前已获得的图像特征，决定下一步采集哪一条扫描线（k-space line） 。
    • 临床导向：目标不再是追求图像的完美重建（SSIM 提升），而是直接面向诊断需求（如：是否发现半月板撕裂） 。
    • 效率最大化：在满足可靠性条件的前提下，用最少的采样步数完成诊断 。

    5. 医学教学与知识工程的“自动化闭环”

    Agent 承担了从原始资料到结构化教学/科研资产的转化任务 。

    • 过程信号建模：MAARTA 系统通过捕捉医生的眼动轨迹（Gaze）和报告文字，分析“为什么漏看”或“哪步想错了”，从而生成个性化教学方案 。
    • 大规模知识构建：MACEE 调度多个 Agent（提取、清洗、对齐、总结）在两周内完成海量超声指南到知识库的转化，极大降低了人工维护成本 。
