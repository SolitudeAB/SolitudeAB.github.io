论文阅读日志：VGGT: Visual Geometry Grounded Transformer

1. 我为什么读这篇论文

我在复现 3DGS 的过程中发现，3DGS 很依赖 COLMAP：

这让我产生了一个问题：

未来有没有可能不用传统 COLMAP 流程，而是直接由模型从图像中预测相机、深度和三维结构？

VGGT 就是围绕这个方向的代表工作之一。

我读 VGGT 的目的不是一开始就完全理解 Transformer 结构，而是先搞清楚：

  • 它和 COLMAP 有什么区别？
  • 它输入什么、输出什么？
  • 为什么说它是前馈式三维重建？
  • 它能不能替代 COLMAP？
  • 它和 3DGS 复现实验有什么关系？

3. 一句话总结

VGGT 是一个前馈式视觉几何 Transformer，目标是直接从图像序列中预测相机参数、深度、点图和点轨迹等三维几何信息，从而减少传统 SfM / COLMAP 中复杂的匹配、三角化和优化流程。

  • 动态物体会影响匹配
  • 长视频处理成本较高
  • 每个任务通常需要不同工具或后处理

5. 输入和输出

5.1 输入

VGGT 的输入可以是一张、少量或很多张图像。

这点和 COLMAP 不同：

  • COLMAP 通常需要多张有重叠的图像
  • VGGT 理论上可以处理一张、少量或上百张图像

对我来说最关键的是：
VGGT 的输出可能能替代 COLMAP 的一部分功能，尤其是相机位姿和三维点相关信息。

7. 什么是前馈式三维重建

这是我读 VGGT 时最重要的收获。

传统 COLMAP 是优化式 pipeline：

VGGT 是前馈式模型：

也就是说，前馈式方法更像深度学习中的“预测”：

  • 输入图片
  • 模型直接给结果
  • 不需要完整传统 SfM 流程中的多轮优化

当然，这并不代表它完全不需要后处理，也不代表它在所有场景都比 COLMAP 更可靠。
我的理解是：它代表一种趋势，但短期内更像是和传统方法互补，而不是简单完全替代。

8. VGGT 和 COLMAP 的区别

对比项 COLMAP VGGT
方法类型 几何优化式 前馈式深度模型
核心流程 特征匹配、三角化、BA Transformer 直接预测
输入 多张图像 一张、少量或多张图像
输出 相机位姿、稀疏点云 相机、深度、点图、点轨迹
优点 几何解释清晰 推理快、任务统一
局限 弱纹理和动态场景容易失败 依赖训练数据和泛化能力

我现在的理解是：

COLMAP 更像传统几何工具，VGGT 更像学习到视觉几何规律的大模型。

10. 我目前读懂的地方

目前比较清楚的点：

  • VGGT 是前馈式三维几何模型
  • 它和 COLMAP 的核心区别是“直接预测”而不是“逐步优化”
  • 它输出的不只是深度，还有相机、点图和点轨迹
  • 它代表三维重建从传统 pipeline 走向视觉几何大模型的趋势
  • 它可能用于替代或辅助 COLMAP，作为 3DGS 的前端

11. 我还没完全懂的地方

目前还不太懂的点：

  1. Transformer 内部如何建模跨视角几何关系
  2. point map 和 depth map 在训练监督上具体有什么区别
  3. VGGT 的相机预测精度和 COLMAP 相比到底如何
  4. VGGT 在手机自采视频上是否稳定
  5. 它是否能直接输出适合 3DGS 使用的相机格式
  6. 长视频输入时显存和速度是否会成为问题
  7. 它的失败场景有哪些

这些问题适合后续通过 demo 或代码测试进一步理解。
