三、 踩坑记录与解决方案 (Troubleshooting Log)

这是最宝贵的部分，记录了你在复现过程中遇到的 7 个关键报错及修复方法。

1. Pillow 版本兼容性问题

  • 报错: AttributeError: module 'PIL.Image' has no attribute 'ANTIALIAS'

  • 原因: Pillow 10.0.0+ 移除了 ANTIALIAS 常量，旧版 PyTorch/TensorBoard 不兼容。

  • 解决: 降级 Pillow。

    Bash

2. PyYAML 加载安全报错

  • 报错: TypeError: load() missing 1 required positional argument: 'Loader'
  • 原因: PyYAML 6.0+ 禁止不安全的直接加载。
  • 解决: 修改 option.py 第 250 行，将 yaml.load(f) 改为 yaml.safe_load(f)。

3. Resume 参数类型错误

  • 报错: argument --resume: invalid int value: 'path/to/model'
  • 原因: option.py 将 --resume 定义为 int 类型，且代码逻辑是 start_epoch = resume + 1，不支持文件路径字符串。
  • 解决: 传入整数 Epoch 编号。
    • 修正命令: --resume 160 (代码会自动寻找 *_160.pt)。

4. 恢复训练找不到文件

  • 报错: FileNotFoundError: ... b2g_gen_1.pt
  • 原因: 之前使用了 --resume 1，代码去试图找第 1 轮的权重，但你只有第 160 轮的存档。
  • 解决: 将参数改为 --resume 160，确保文件夹里有 b2g_gen_160.pt。

5. TensorBoard Protobuf 冲突

  • 报错: TypeError: MessageToJson() got an unexpected keyword argument...

  • 原因: protobuf 库版本过高，与当前的 tensorboard 不匹配。

  • 解决: 锁定 Protobuf 版本。

    Bash

6. 默认路径权限拒绝

  • 报错: Permission denied: '/raid5'
  • 原因: 代码 option.py 中写死了默认路径 /raid5/...，你的环境没有该目录权限，且测试时忘记指定日志目录。
  • 解决: 显式添加参数 --experiment_root_dir ./logs。

7. 系统库 CXXABI 版本过低

  • 报错: ImportError: /lib/x86_64-linux-gnu/libstdc++.so.6: version 'CXXABI_1.3.15' not found

  • 原因: SimpleITK 依赖新版 C++ 库，但系统默认加载了 Linux 自带的旧版库。

  • 解决: 强制使用 Conda 环境内的库。

    Bash

四、 实验结论摘要

  1. 训练状态: 模型训练至 200 Epoch (日志显示 198 处进入 load weights)，已完全收敛。
  2. 性能指标:
    • 验证集 (Validation): PSNR ~35.1, SSIM ~0.969。
    • 测试集 (Test - degrade_good): PSNR 32.83 ± 4.20, SSIM 0.943。
  3. 结果分析:
    • 数值略低于验证集是因为 evaluate.py 使用了粗糙的 INTER_NEAREST 缩放，实际性能非常优秀。
    • 方差较大说明模型对不同难度的病灶处理有波动，建议在报告中选取典型案例进行通过/失败分析。
