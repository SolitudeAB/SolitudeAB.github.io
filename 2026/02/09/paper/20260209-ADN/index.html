ADN：用于无监督金属伪影消除的伪影解缠网络 [论文]

作者： 廖浩夫 （liaohaofu@gmail.com），2019 年春

引用文献

若在研究中使用了本代码，请引用我们的论文。

前提条件

本代码库已在以下系统环境中完成测试：

  • Ubuntu 16.04
  • Python 3.7（推荐使用 Anaconda/Miniconda）
  • Pytorch 1.0.0 或更高版本
  • CUDA 9.0 或更高版本
  • Matlab R2018b（包含图像处理工具箱、并行计算工具箱以及统计和机器学习工具箱）

安装

本地

对于大多数用户，您可以按照以下步骤在本地计算机上安装 ADN。

  • 从 Github 克隆此代码库
  • 安装 Pytorch 和 Anaconda/Miniconda
    • Anaconda/Miniconda 安装为可选步骤。若未安装，您可能需要手动安装部分依赖的 Python 软件包
  • 安装 Python 依赖包

Docker

对于 Docker 用户，我们提供了预构建的 docker 镜像以及 Dockerfile。

  • 安装 docker-ce 和 nvidia-docker
  • 从 Docker Hub 拉取 ADN docker 镜像。这将自动安装 ADN 及其依赖项。
  • [可选] 如需定制 ADN 的 Docker 镜像版本，可修改 docker/Dockerfile 文件后自行构建镜像。
  • 运行 ADN docker 镜像

数据集

支持两个公开数据集（DeepLesion 和 Spineweb）。作为补充，我们还支持自然图像的训练/测试。

DeepLesion

  • 下载 DeepLesion 数据集 。我们在实验中使用了前 9 个 .zip 文件（从 Images_png_01.zip 到 Images_png_09.zip）。您可以使用 DeepLesion 提供的批量下载功能一次性下载所有 .zip 文件。batch_download_zips.py
  • 解压已下载的 .zip 文件。所有解压后的图像将存放在文件夹中。此处是您解压 .zip 文件的文件夹路径。 path_to_DeepLesion/Images_png/ path_to_DeepLesion
  • 创建指向 DeepLesion 的软链接。 在执行以下命令前，请将 path_to_DeepLesion/Images_png 替换为您系统中的实际路径 。
  • 为 ADN 准备 DeepLesion 数据集（ 需要 MATLAB）。准备 DeepLesion 数据集的配置文件位于。config/dataset.yaml

脊柱网

  • 下载 Spineweb 数据集 。
  • 解压 spine-\.zip 文件（即、、等）。所有解压后的图像将存放在文件夹中。此处是您解压 spine-*.zip 文件的文件夹路径。`spine-1.zipspine-2.zippath_to_Spineweb/spine-/`path_to_Spineweb
  • 创建指向 Spineweb 的软链接。 在运行以下命令前，请将 path_to_Spineweb/ 替换为系统中实际路径 。
  • 为 ADN 准备 Spineweb 数据集。准备 Spineweb 数据集的配置文件位于。config/dataset.yaml

自然图像

  • 我们的代码假设您已按以下方式准备自然图像数据集。
  • 创建指向自然图像数据集的软链接
  • 请注意，我们的模型并未针对自然图像进行调优（例如损失函数、超参数等的选择），其效果可能因具体问题和数据集而异。

演示

  • 我们提供演示代码以展示 ADN 的有效性。输入样本图像位于，演示输出结果可在找到。运行演示时，samples/``results/

  • [可选] 默认情况下，演示代码会自动从谷歌云端硬盘下载预训练模型。若自动下载失败，您可手动从谷歌云端硬盘下载这些模型。

    • 从 Google 云端硬盘（DeepLesion | Spineweb）或 Bitbucket 下载预训练模型。
    • 将下载的模型移至。runs/

训练与测试

  • 配置训练与测试。我们为 ADN 采用两阶段配置，一阶段为默认设置，另一阶段为运行设置。
    • ADN 的默认设置可在中查看，这些设置不可更改。当用户未提供特定设置的值时，将使用此文件中的默认设置。config/adn.yaml
    • 运行设置可在 runs/adn.yaml 中找到。此处供用户为 ADN 的训练和测试提供具体设置。实验中，该文件提供的任何设置都将覆盖默认设置。 默认情况下，使用 DeepLesion、Spineweb 和自然图像数据集训练及测试 ADN 的设置均提供于 runs/adn.yaml 中。
  • 使用 DeepLesion、Spineweb 数据集或自然图像数据集训练 ADN。训练结果（模型检查点、配置文件、损失值、训练可视化等）可在以下路径中找到：runs/run_name/，其中 run_name 可以是 deep_lesion、spineweb 或 nature_image
  • 使用 DeepLesion、Spineweb 数据集或自然图像数据集测试 ADN。测试结果（评估指标和测试可视化等）可在以下路径中找到：runs/run_name/``run_name``deep_lesion``spineweb``nature_image
