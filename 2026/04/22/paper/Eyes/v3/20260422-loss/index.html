面向 PSNR 与临床结构保真的损失函数设计（PMEG-SCR 改进版）

1. 目标与核心矛盾分析

在眼底图像增强任务中，现有的优化准则面临以下瓶颈：

  • 指标脱节：使用纯 $L_1$ 或 $MSE$ 往往能获得极高的 SSIM（如 94+），但 PSNR 提升微弱（仅 1dB 左右），原因在于模型对“离群崩坏像素”缺乏惩罚。
  • 局部误差敏感性：PSNR 对绝对像素误差极度敏感，极少数的极端错误点（如伪影区、高光区）会显著拉低全局 PSNR 指标。
  • 临床保真度冲突：原 SCR-IG 框架偏重于病灶与拓扑结构的恢复，虽然提升了临床可用性，但在数学上并未直接最大化像素级的 PSNR。

因此，本方案提出一种多维双目标损失函数，旨在稳步提升 PSNR 的同时，确保微米级病灶与血管拓扑的保真。

2. 统一损失函数定义

定义预测图为 $\hat{Y}$，真实标签为 $Y$。令复合重要性先验 $\bar{\alpha} = \max(\alpha{lesion_s}, \alpha{vessel})$。像素级误差记为 $E = |\hat{Y} - Y|$。

总损失函数 $\mathcal{L}_{total}$ 构造如下：

2.1 PSNR 主导损失（MSE）

直接针对 PSNR 的数学定义进行优化，是提升指标的基石：

  • 作用：在训练全周期保持主导权重，确保模型收敛于像素级的平均值。

2.2 硬样本离群惩罚（Hard Mining）

专门治理导致 PSNR 无法突破的“崩坏像素”。设 $TopK(E^2)$ 为全图误差平方最大的前 $k\%$ 像素集合：

  • 作用：强效压制离群点。建议初期 $k=5\%$，随着训练进行降至 $1\%$，精准歼灭残余的异常噪声点。

2.3 病灶重要性重建（Pathological Reconstruction）

继承原论文对病理区域的关注，但通过指数平滑控制其对全局 MSE 的冲击：

  • 作用：确保出血、渗出等高危病灶在增强后具备更高的对比度与可见度。

2.4 重要性调制平滑（IMS）

抑制背景散斑噪声，同时保护结构边缘：

  • 作用：在健康背景区执行强力平滑，在病灶区执行保边去噪。

2.5 软骨架拓扑一致性（clDice）

针对微血管连通性的高阶形态学约束：

  • 作用：强制血管端点与分叉处的拓扑守恒，规避假阴性断裂。

3. 两阶段课程学习策略

为解决多目标优化中的梯度冲突，建议采用以下调度策略：

Phase I：基础重构与 PSNR 攻坚（前 60% Epochs）

目标是建立稳健的光照基线，消除大面积退化。

  • 损失配置：$\mathcal{L} = 1.0\mathcal{L}{mse} + 0.3\mathcal{L}{hard} + 0.1\mathcal{L}{patho} + 0.05\mathcal{L}{ims}$
  • 状态：$\mathcal{L}_{clDice}$ 设为 0。此阶段优先保证像素级的快速咬合。

Phase II：结构精修与拓扑锁定（后 40% Epochs）

在 PSNR 稳定的基础上，注入高阶医学语义。

  • 损失配置：$\mathcal{L} = 1.0\mathcal{L}{mse} + 0.2\mathcal{L}{hard} + 0.15\mathcal{L}{patho} + 0.1\mathcal{L}{ims} + 0.1\mathcal{L}_{clDice}$
  • 注意：若观察到 PSNR 下滑，应优先下调 $\lambda_{topo}$。

4. 相比原 SCR-IG 损失的关键改进

  1. 新增离群治理：原论文未显式约束最差像素，$\mathcal{L}_{hard}$ 填补了 PSNR 提升的工程空白。
  2. 权重引力中心偏移：本方案重新确立了 $\mathcal{L}_{mse}$ 的核心地位，将“病理导向”转变为“保底像素，点控病灶”。
  3. 约束解耦：将拓扑损失 $\mathcal{L}_{clDice}$ 移至后期启用，减少了训练初期对像素收敛的干扰。
  4. 动态日程表：强调了从“量”（PSNR）到“质”（拓扑）的阶段性演进，而非固定权重的混合。

5. 实验建议与指标验证

固定 512 尺度输入，建议进行以下四组消融实验以验证 PSNR 的稳步提升：

实验组 损失组合 预期效果
Exp 1 $MSE$ (Baseline) PSNR 基本盘，SSIM 适中。
Exp 2 $MSE + Hard$ PSNR 显著提升，消除明显的局部伪影坏点。
Exp 3 $MSE + Hard + Patho + IMS$ 保持 PSNR 的同时，病灶对比度与背景纯净度大幅改善。
Exp 4 Full PMEG-SCR Loss 实现指标与临床拓扑连通性的双重最优。

评估维度：

  • 全局指标：PSNR / SSIM。
  • 坏点治理：计算最差 5% 样本的平均 PSNR，验证系统鲁棒性。
  • 临床评价：针对微血管断裂点进行局部可视化分析。
