3.1 Overview of the Architecture

现有的低照度眼底图像增强算法普遍面临“物理平滑与病理保真”之间的本征矛盾。针对此瓶颈，本文提出了一种语义校准的 Retinex 重要性引导框架（SCR-IG）。该框架打破了传统 Retinex 模型中各向同性（Isotropic）的光照估计假设，将多维医学语义先验深度注入到光照残差的映射过程中。如图 X 所示，SCR-IG 包含三个核心组件：基于非对称知识蒸馏的多维语义先验生成模块（KD-SIPG）、基于多分支门控的条件变异光照校准模块（Cond-SVIC），以及确保边缘端极低延迟的自校准推理机制（SCM）。在统一的拓扑感知与课程学习优化景观下，该网络能够在极度退化的图像中实现微米级的病灶保留与高置信度的光照恢复。

3.2 Asymmetric Knowledge Distillation for Semantic Prior Generation (KD-SIPG)

在极低信噪比与不均匀照明的眼底成像退化空间中，直接提取可靠的病理结构是一个典型的不适定问题。KD-SIPG 旨在不增加边缘部署算力负担的前提下，构建一个稳健的、包含多维解剖先验的重要性张量 $\boldsymbol{A} \in \mathbb{R}^{H \times W \times 4}$。

物理拓扑流（Physical Topological Baseline）：

为克服极暗区域引起的 Hessian 矩阵特征值失效，输入观测图像 $y$ 首先经过全局环境光池化提取极低频基线 $x_{rough}$，计算粗略反射分量 $z_{rough} = y \oslash x_{rough}$。为抵御非散瞳设备中常见的强高光反射与睫毛遮挡伪影，引入基于 Otsu 的物理异常掩码（Artifact Mask）$\mathcal{M}_{art}$。最终的管状拓扑概率分布由可微分多尺度 Frangi 滤波器结合掩码生成：

$\alpha_{vessel} = \text{Frangi}(z_{rough}) \odot (1 - \mathcal{M}_{art})$

此过程确保了微血管形态学先验的拓扑连通性，且对局部高频伪影具有绝对免疫力。

双轨非对称语义蒸馏（Asymmetric Semantic Distillation）：

为跨越大型医疗基础模型与轻量级边缘网络之间的容量鸿沟（Capacity Gap），本研究引入了教师助手知识蒸馏（TAKD）策略。在训练域内，冻结权重的视网膜基础大模型（如 RETFound）作为 Teacher $\mathcal{T}$，提取高维潜空间特征并映射为病灶概率 $\alpha_{lesion\_t}$。同时，计算其输出分布的像素级信息熵以量化不确定性图 $U_{t}$。

轻量级 Student 网络 $\mathcal{S}$（实际部署的感知机）以联合分布 $[y, z_{rough}]$ 为输入，通过最小化 Kullback-Leibler 散度拟合 Teacher 的输出边界。最终，生成融合多维重要性的导航张量：

$\boldsymbol{A} = [\alpha_{lesion\_s}, \alpha_{vessel}, U_{s}, 1 - \max(\alpha_{lesion\_s}, \alpha_{vessel})]$

其中最后一项代表视网膜健康背景的置信度。由于网络在推理时切断了 Teacher 模型，KD-SIPG 实现了零样本医学先验向极轻量算子的无损下沉。

3.3 Gated Multi-branch Conditional Variance Illumination Calibration (Cond-SVIC)

在获取重要性张量 $\boldsymbol{A}$ 后，核心增强任务被建模为基于先验的空间变异光照残差估计：$x^{t+1} = x^t + \mathcal{H}_{\theta}(x^t | \boldsymbol{A})$。为规避像素级动态卷积带来的参数量爆炸与显存溢出（OOM）问题，Cond-SVIC 采用多分支门控注意力机制在数学上等效实现了差异化特征调制。

首先，光照特征 $x^t$ 接受空间自适应归一化（SPADE）的像素级激活调制。$\boldsymbol{A}$ 经由浅层映射预测仿射参数张量：

$\tilde{x}^t = \text{Norm}(x^t) \odot \gamma(\boldsymbol{A}) + \beta(\boldsymbol{A})$

随后，调制特征 $\tilde{x}^t$ 进入并行静态卷积域，该域由高通边缘强化分支 $\mathcal{B}_{high}$、低通平滑分支 $\mathcal{B}_{low}$ 与恒等映射分支 $\mathcal{B}_{id}$ 构成。空间路由权重矩阵 $\boldsymbol{W} \in \mathbb{R}^{H \times W \times 3}$ 由 $\boldsymbol{A}$ 经卷积与 Softmax 激活生成。最终的等效空间变异光照残差 $u^t$ 表现为多通道输出的加权积分：

$u^t = \sum_{k \in \{high, low, id\}} \boldsymbol{W}_k \odot \mathcal{B}_k(\tilde{x}^t)$

该设计通过严谨的矩阵运算流，完美解耦了“病理/血管高频保护”与“背景低频散斑平滑”的正交需求。

3.4 Self-Calibrated Inference and Topologically-Aware Loss Landscape

为了确保该框架能够下沉至便携式诊疗设备，本研究继承并深化了自校准机制（SCM）。在训练阶段，光照残差映射 $\mathcal{H}_{\theta}$ 在时间步上展开为 $T$ 个级联阶段（阶段间共享权重 $\theta$）。为了促使映射逼近压缩函数并收敛至稳定流形，除常规阶段惩罚外，我们在特征域引入了强收敛约束：

$\mathcal{L}_{SCM\_feat} = \| \gamma^{T-1} - \gamma^{T-2} \|_2^2 + \| \beta^{T-1} - \beta^{T-2} \|_2^2$

在上述约束下，模型仅需在测试时执行一次前向传播（$T=1$）即可逼近无穷级联的极值，实现极速单模块推理。

为解决复杂多目标优化中的梯度冲突，本框架采用两阶段课程学习（Curriculum Learning）策略优化损失景观。令复合重要性标量 $\bar{\alpha}_i = \max(\alpha_{lesion}^{(i)}, \alpha_{vessel}^{(i)})$。

Phase I (基础重构与调制平滑): 旨在建立光照均匀性与初步去噪。联合损失包含带指数权重的监督保真损失 $\mathcal{L}_{IS\_Retinex}$ 与重要性调制的全变分平滑约束 $\mathcal{L}_{IMS\_v2}$：

$\mathcal{L}_{IMS\_v2} = \sum_{i} \sum_{j \in \mathcal{N}(i)} \left[ (1 - \bar{\alpha}_i) w_{i,j} |x_i - x_j| + \lambda_{TV} \bar{\alpha}_i \text{TV}_{edge}(x_i) \right]$

乘子 $(1 - \bar{\alpha}_i)$ 物理截断了病理区域的全局平滑，而保边全变分（TV）项则为病灶区提供防噪底线。

Phase II (特征收敛与拓扑恢复): 在稳定的图像空间中，激活 $\mathcal{L}_{SCM\_feat}$ 逼近稳定流形，并引入软骨架拓扑损失 $\mathcal{L}_{clDice}$。该损失通过数学形态学操作提取网络输出与真实标签的骨架连通性，强制增强网络在血管端点与分叉处保持高度的拓扑守恒，彻底规避了假阴性断裂。

3.5 Topologically-Aware Objective Function and Curriculum Learning

由于 SCR-IG 框架面临着“消除背景噪声”、“保护病理细节”与“恢复血管拓扑”等多重优化目标，传统的静态权重组合极易引发梯度冲突（Gradient Conflict）。为此，本研究设计了基于两阶段课程学习（Curriculum Learning）的拓扑感知目标函数。令 $\bar{\alpha}_i = \max(\alpha_{lesion}^{(i)}, \alpha_{vessel}^{(i)})$ 为融合重要性标量。

1. 基础保真与调制平滑损失 (Phase I)

在第一阶段（Phase I），网络的主要任务是建立均匀的光照基线并消除低频退化。我们联合优化监督重构与无监督平滑。

带有指数惩罚的监督 Retinex 重构损失定义为：

$\mathcal{L}_{IS\_Retinex} = \frac{1}{N}\sum_{i=1}^{N}\frac{1}{\exp(\lambda_{is} \bar{\alpha}_{i})} \| z_{pred}^{(i)} - z_{GT}^{(i)} \|_{2}^{2} + \frac{1}{N}\sum_{i=1}^{N}\bar{\alpha}_{i}$

该损失强制网络对高危病灶区赋予极高的重构梯度。同时，为防止无监督平滑破坏血管，引入重要性调制平滑损失 $\mathcal{L}_{IMS\_v2}$：

$\mathcal{L}_{IMS\_v2} = \sum_{i} \sum_{j \in \mathcal{N}(i)} \left[ (1 - \bar{\alpha}_i) w_{i,j} |x_i - x_j| + \lambda_{TV} \bar{\alpha}_i \text{TV}_{edge}(x_i) \right]$

此外，贯穿整个训练周期的知识蒸馏损失 $\mathcal{L}_{KD}$ 用于对齐 Teacher 与 Student 的先验分布：

$\mathcal{L}_{KD} = \text{KL}(\alpha_{lesion\_s} \| \alpha_{lesion\_t}) + \text{KL}(U_{s} \| U_{t})$

第一阶段的总损失 $\mathcal{L}_{Phase\_I}$ 定义为：

$\mathcal{L}_{Phase\_I} = \mathcal{L}_{IS\_Retinex} + \omega_1 \mathcal{L}_{IMS\_v2} + \omega_2 \mathcal{L}_{KD}$

2. 拓扑恢复与特征收敛损失 (Phase II)

在光照基线稳定后，第二阶段（Phase II）引入更严苛的高阶形态学与特征域约束。为了确保毛细血管的拓扑连通性，引入软骨架 Dice 损失 $\mathcal{L}_{clDice}$：

$\mathcal{L}_{clDice} = 1 - 2 \frac{|S_{pred} \cap V_{GT}| + |V_{pred} \cap S_{GT}|}{|S_{pred}| + |V_{GT}| + |V_{pred}| + |S_{GT}|}$

其中 $S$ 和 $V$ 分别代表提取的软骨架（Soft Skeleton）与血管分割掩码。

同时，激活自校准特征约束 $\mathcal{L}_{SCM\_feat}$，强制级联模块的仿射调制参数在最后两个阶段（$T-1$ 和 $T-2$）逼近常数矩阵：

$\mathcal{L}_{SCM\_feat} = \| \gamma^{T-1} - \gamma^{T-2} \|_2^2 + \| \beta^{T-1} - \beta^{T-2} \|_2^2$

最终，第二阶段的总目标函数 $\mathcal{L}_{Total}$ 定义为：

$\mathcal{L}_{Total} = \mathcal{L}_{Phase\_I} + \omega_3 \mathcal{L}_{clDice} + \omega_4 \mathcal{L}_{SCM\_feat}$

(注：经验上，超参数 $\omega_1, \omega_2, \omega_3, \omega_4$ 用于平衡各梯度量级，我们将在实现细节部分详细探讨其设置。)
