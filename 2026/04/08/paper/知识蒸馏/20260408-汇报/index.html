Page 02 / Method (重点聚焦 CQA 的构建与训练)

Page 2: CQA 的基石——昂贵且真实的“医生反馈” (数据标注)

  • (讲解图表：引导大家看 Fig. 1 里的 Radiologists 图标或单独列出打分规则)
  • 口语讲解引导： “在讲 CQA 网络结构之前，我们先来看看它的‘灵魂’从何而来。为了避免半监督学习中的确认偏差，最理想的情况是让医生坐在电脑前，人工筛选模型生成的每一张图 。但这在现实中是不可能的。” “因此，作者提出构建一个临床质量评估数据集，本质上是把放射科医生的经验‘蒸馏’下来 。作者请了两位经验丰富的放射科医生，对大量的 CT 图像进行 1-10 分的李克特量表（Likert scale）打分 。1分代表组织严重畸变，10分代表无伪影且解剖结构完美 。对于没有真实参考标准（Ground-Truth）的临床图，他们采用了‘初审+复审’的模式——一位医生先打分，另一位资深医生复核，最终达成共识 。这可以说是整个框架中最耗费人力，但也最关键的一步，因为它定义了什么是‘临床可用’。”

Page 3: CQA 的训练机制——如何让模型学会“医生的眼光”

  • (讲解图表：重点讲解 Fig. 2 的训练流程，特别是拉近/推远的示意图)
  • 口语讲解引导： “有了医生们辛苦打出的高质量标签，接下来就是如何训练 CQA 模型去学习这种标准。” “首先，因为不同去伪影算法处理后的图像，质量差异可能非常细微，作者提出了一种叫 DQAug（多样化质量增强） 的策略 。他们用训练不足的 MAR 算法去生成中等质量的图，并用 MixUp 技术把不同质量的图混合，强行给模型‘喂’各种难度的样本，逼迫它看懂细微的失真 。” “其次，大家请看图 2。在损失函数的设计上，作者采用了一个复合损失函数 $\mathcal{L}_{cqa}$ 。除了常规的交叉熵损失 $\mathcal{L}_{ce}$ 用于 10 分类的概率预测外，他们还专门引入了监督对比损失（Supervised Contrastive Loss, $\mathcal{L}_{scl}$） 。如图所示，这个损失函数的作用是把那些医生打分相同的图像特征在隐空间中‘拉近’，把打分不同的图像特征‘推远’ 。通过这种方式，CQA 模型才真正学会了如何像放射科医生一样，对细微的图像质量差异进行敏感的区分。”

05 / Proposed Solution (核心破局点：从人工到 Agent)

  • Page 5: 引出多 Agent 蒸馏框架
    • 核心理念：抛弃昂贵的人工标注，采用“大模型打分出分布，小模型蒸馏学特征”的全新范式。
    • 三步走战略：第一阶段（多 Agent 虚拟会诊，构建高质量先验）、第二阶段（基于概率分布的混合蒸馏，训练本地小模型）、第三阶段（零成本本地化推理）。
    • 口语讲解引导：“正如刚才提到的，依赖两名真实医生去打分，成本极高且无法规模化。那么，我们能不能请几位不知疲倦的‘AI 专家’来代劳呢？这就是我们要提出的全新解决方案：基于多 Agent 协作与概率分布拟合的蒸馏框架。我们将整个过程分为三个阶段，彻底解决 CQA 标注难、泛化差的问题。”

06 / Phase 1: 专家会诊 (构建虚拟专家委员会)

  • Page 6: 组建具有“客观工具”的虚拟会诊室
    • 物理扩增 (Physical Augmentation)：先通过算法引入符合医疗光学规律的缺陷（过曝、遮挡、散焦），将小批量样本（如 100 张）扩增至 1000 张，为 Agent 准备“复杂考卷”。
    • 多源打分与客观武装 (Multi-Agent + Tools)：同时接入 3-5 个顶级多模态大模型（如 GPT-4o、Claude 3.5）。给它们配备 RAG（临床指南手册）和外部脚本工具（如血管分割率、亮度对比度计算器）。
    • 口语讲解引导：“在第一阶段，我们要从小批量数据中榨取最大的信息量。我们不仅模拟出逼真的临床伪影，还组建了一个‘虚拟专家委员会’。这里面包含了 GPT-4o、Claude 等多位不同流派的顶级专家。重点是，我们不让它们瞎猜，而是给它们发‘医疗器械’（外部脚本工具返回的量化数据），并强制它们完成标准化的问卷（ICARE机制）。这样它们生成的思维链（CoT）就有了绝对的客观支撑。”
  • Page 7: 核心升级：从“死板的单点得分”到“概率分布”
    • 分布生成 (Probability Distribution)：针对同一张图，收集 5 位专家的得分（例如 [85, 82, 88, 85, 80]），计算出一个高斯分布（均值 $\mu$ 与 方差 $\sigma$）。
    • 口语讲解引导：“这是我们第一阶段最大的亮点。传统方法强迫模型给出一个具体的死分数，比如 84 分，这是极其不合理的。现实中医生们也会有分歧！因此，我们不取平均值，而是生成一个高斯分布：均值代表图像的总体质量倾向，而方差代表了这张图的‘不确定性’（专家间的分歧度）。”

07 / Phase 2: 混合蒸馏 (教小模型学分布)

  • Page 8: 基于 KL 散度与置信度驱动的学习
    • 分布拟合 (Distribution Fitting)：抛弃传统的均方误差（MSE），使用 KL 散度强迫轻量级学生网络去拟合第一阶段生成的“专家打分高斯分布”。
    • UDCD 激活与 RL 探索：利用“方差”作为最完美的置信度指标。方差小（无分歧）则老实学习分布；方差大（遇罕见伪影导致严重分歧），则切断直接监督，触发 UDCD（不确定性驱动的对比自蒸馏）增强对比学习。并引入强化学习（GRPO），奖励那些落在高置信度区间的推理路径。
    • 口语讲解引导：“拿到专家的‘分布’诊断书后，第二阶段我们要把这些知识传授给一个轻量级的本地小模型。我们用 KL 散度让小模型去拟合专家的概率分布。更精妙的是，我们把‘方差’当成了天然的置信度指标：如果专家们一致认同，小模型就直接学；如果专家们吵起来了（方差极大），系统就会自动触发内部的对比自蒸馏机制，让小模型自己去摸索特征边界。我们还加入了强化学习，让小模型越学越聪明。”

08 / Phase 3 & Conclusion (大规模部署与临床价值)

  • Page 9: 具备“不确定性感知”的零成本推理
    • 自带信心指数：彻底切断昂贵的 API，全量本地化部署。模型输出多维质量指标的同时，自带置信区间（方差）。
    • 高低信心拦截：置信度高直接过检；置信度极低（方差大），自动拦截并提示“需人工介入”。
    • 硬核技术挑战壁垒：简述项目需要攻克的难题（避免大模型幻觉、控制高并发 API 烧钱率、逼真而不只是“像PS过”的物理造假）。
    • 口语讲解引导：“经过前两步，我们最终得到了一个全本地化、零 API 调用成本的轻量级模型。当面对海量未标注的真实临床数据时，它不仅能瞬间给出质量评分，还能给出一个‘信心指数’。遇到它拿不准的刁钻伪影，它会自动举手呼叫人类医生介入。当然，要实现这个闭环，我们在物理伪影逼真度、大模型幻觉压制以及高并发调度上还有几块硬骨头要啃，但这种自带信心预警的机制，才真正契合真实的临床工作流！”
